## 🌿 About the Project

The **Kanyi J. & Company Advocates** website is a modern online platform created to give the law firm a professional digital presence and make its services more accessible to clients and visitors.

Designed with elegance, clarity, and usability in mind, the website provides an engaging introduction to the firm while making it easier for prospective and existing clients to explore information and access relevant services.

The experience brings together a refined visual identity, intuitive navigation, and thoughtful interactions to reflect the professionalism expected of a contemporary legal practice.

## ✨ What the Website Offers

### ⚖️ A Professional Firm Introduction
A welcoming homepage that introduces the firm, communicates its identity, and provides visitors with a clear starting point for exploring its services.

### 📖 Informative Content
Well-organized sections that help visitors understand the firm, its areas of practice, and the professional services it offers.

### 📊 Firm Highlights
An engaging presentation of key firm statistics and achievements, using animated counters to make important information more memorable.

### 📱 Seamless Browsing Experience
A fully responsive design that adapts to mobile phones, tablets, and desktop computers, ensuring visitors can access the website wherever they are.

### 🌗 Personalized Viewing Experience
Visitors can switch between light and dark themes, with support for their device's preferred appearance.

### 🎬 Smooth Visual Interactions
Subtle animations, elegant transitions, and interactive elements create a polished browsing experience without compromising usability.

### 🔗 Client Portal Access
Convenient access to the firm's external client portal, connecting the public website with its digital client services.

## 🎨 Design Philosophy

The website embraces a simple but deliberate design philosophy:

- **Trust:** A professional presentation that inspires confidence.
- **Clarity:** Information presented in an accessible and organized manner.
- **Elegance:** A refined visual experience that avoids unnecessary clutter.
- **Accessibility:** A consistent experience across different devices and screen sizes.
- **Modernity:** Thoughtful animations and interactions that enhance, rather than distract from, the content.

## 🛠️ Built With

The website is powered by modern web technologies, including:

- Next.js
- TypeScript
- Tailwind CSS
- Shadcn UI
- Framer Motion
- Lucide Icons
- Firebase App Hosting

These technologies work together to deliver a responsive, interactive, and maintainable digital experience.

## 🚀 Running the Project Locally

Want to explore or contribute to the project?

**Requirements**
- Node.js (v18 or later recommended)
- npm or yarn

**Installation**

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
npm install
npm run dev
```

Open [http://localhost:9002](http://localhost:9002) in your browser to explore the website.

## 🌍 Deployment

The website is configured for deployment through Firebase App Hosting.
